# Onboarding Video Artifacts

This folder holds tracked final renders from the internal onboarding-video tooling.

The default `landing-demo` command writes the canonical MP4 here:

```text
research/onboarding-video-artifacts/chrome-landing-tabs-demo.mp4
```

Keep raw captures, click logs, compiled native helpers, and other scratch files under
`.tmp/onboarding-video-tools/`. Only commit final artifacts here when we intend to keep them on file
in the repo.
