# The Concentrate Metaphor For Samebase

## Document Control

- Status: Research synthesis, not an accepted positioning contract

## Recommendation

Use the metaphor as a campaign hook, especially in a 20 to 40 second video. Do not make it the
permanent definition of Samebase or the landing-page hero.

The useful thought is:

> If you already use a coding agent, you already have the AI. Samebase gives that agent the proven
> base and operating actions needed to turn code into apps that stay yours and stay manageable.

The unsafe version is:

> Other app builders mostly resell AI, while Samebase sells concentrated knowledge that produces the
> same thing more cheaply.

That version overstates the sameness, understates competitors' real managed value, and misstates
Samebase's product. Samebase publishes the knowledge for free. Its value is compression into
execution, provider connections, durable state, inventory, verification, and repair.

The metaphor should earn attention and then resolve into literal product truth within 5 to 7
seconds. Keep "same base" as the durable brand thesis.

## Why The Metaphor Works

### It makes invisible duplication visible

The user already has Codex, Claude Code, Cursor, or another coding agent. A second AI chat surface
inside an app builder can therefore feel like buying an input twice. A bottle full of water makes
that duplication tangible without a diagram.

This maps directly to the current landing claim:

> We resell nothing. Not tokens, not hosting.

The rest of that live claim is equally important: users already pay their AI and infrastructure
providers directly, while Samebase supplies a different layer.

### It explains compression

Existing pitch language already says the knowledge is free and the user pays for compression: one
action instead of an afternoon. Concentrate is a physical expression of that compression.

### It is naturally cinematic

Concentrate products have a transformation that needs almost no explanation: fill, drop, mix, use.
[OceanSaver](https://www.ocean-saver.com/pages/aboutpods) presents exactly that sequence and says
the active ingredient in cleaning sprays is often less than 10 percent of the liquid.
[Blueland](https://www.blueland.com/pages/product-philosophy) makes the contrast memorable with a
small tablet, a heavy liquid bottle, and quantified transport reduction.

The Samebase version can move from a bulky builder containing another AI, to the agent already on
the user's computer, to the concrete base that the agent can operate.

### Metaphors can improve recall when the meaning stays explicit

Advertising research has found stronger recall for ads using rhetorical figures and for metaphorical
ads compared with functional ads. The same literature also shows the failure mode: complexity can
outweigh comprehension. A 2022 study on visual metaphor design found that accurate comprehension was
associated with conceptual similarity, explicitness, direct verbal messages, and low visual
complexity ([Takeuchi and Wang](https://doi.org/10.7222/marketing.2022.033)).

That supports a simple creative rule: show the analogy, name the mapping, and leave the analogy
quickly.

## Where The Mapping Is Accurate

| Concentrate system                        | Samebase mapping                                                   |
| ----------------------------------------- | ------------------------------------------------------------------ |
| Water is locally available                | The user already chose and pays for a coding agent                 |
| Active formula is the scarce part         | The proven base and operational actions are the missing part       |
| Add water at the point of use             | Invoke Samebase from the user's existing agent                     |
| Reuse the bottle                          | Keep using normal repositories and provider accounts the user owns |
| Small input produces the finished mixture | One action provisions and wires a real app                         |
| Repeat the same dilution                  | Repeat one base across the second, fifth, and tenth app            |

The mapping is strongest for explaining why Samebase does not bundle or resell AI. It is also useful
for explaining why an opinionated base becomes more valuable across many apps.

## Where The Mapping Breaks

### AI is not interchangeable water

Model quality, agent behavior, context, tools, and user preference matter. Saying "AI is water" too
literally can sound dismissive of the user's choice or imply that all models are equal.

Use:

> You already chose your coding agent.

Do not use:

> AI is a commodity and every model is the same.

### Other builders do more than resell tokens

Competitors also sell interface design, sandboxes, deployment, collaboration, support, and a managed
runtime. The concentrate comparison is therefore not a complete category analysis.

The defensible claim is that Samebase does not force an existing coding-agent user to buy another
bundled AI interface. It is not defensible to say every competing fee is only margin on water.

### Samebase is not secret knowledge in a packet

The do-it-yourself guide and receipts deliberately make the knowledge public. A static recipe or
template also cannot represent the living inventory and repair layer.

The closest accurate noun is **operational compression**:

- one action instead of manual cross-provider setup;
- provider state and coordinates in one inventory;
- a standard app base that both people and agents can inspect;
- explicit actions to repair drift;
- apps that remain in the user's accounts if Samebase disappears.

### "Same value for less" is not yet a supported pricing claim

Concentrate brands can measure volume, weight, and transport. Blueland says its tablets are about 90
percent lighter and that one truck of tablets can replace up to 83 trucks of liquid cleaner.
Samebase has no equivalent verified ratio for total app-builder cost or time saved.

The public claim should stay mechanistic:

- no resale of AI tokens;
- no resale of hosting;
- direct provider billing;
- an idle app can fit the providers' free tiers;
- the core provisioning and inventory flow is free today.

Do not claim universally lower total cost until a like-for-like comparison is receipted.

### "Just connect your AI" hides real onboarding

The product currently asks for provider OAuth connections and a GitHub app. A concentrate animation
suggests near-zero setup. The video must either show the actual connections or scope itself to
people who have already connected Samebase.

## What Adjacent Products Teach

Concentrate brands do not rely on "less water" alone. They add three proof layers:

1. a visible ritual;
2. a quantified compression ratio;
3. proof that the result still performs.

[Blueland](https://www.blueland.com/pages/product-philosophy) pairs the tablet with weight and truck
comparisons. [OceanSaver](https://www.ocean-saver.com/pages/aboutpods) shows the three-step
transformation. [JAWS](https://jawscleans.com/pages/about-jaws) makes "Stop Shipping Water" a
principle, then immediately explains its reusable bottle and concentrated refill system.

Bring-your-own-model products show a second lesson: supplying the AI is already a familiar feature,
not a unique category.

- [GitHub Copilot](https://docs.github.com/en/copilot/concepts/models/bring-your-own-key) describes
  bring-your-own-key in terms of model choice, cost savings, consolidated billing, and reduced
  dependency on GitHub's model API.
- [Dyad](https://www.dyad.sh/) combines favorite models, owned code, local operation, and zero
  lock-in.
- [OpenRouter](https://openrouter.ai/blog/announcements/1-million-free-byok-requests-per-month/)
  explains what remains valuable above customer-supplied model keys: failover, extra capacity, spend
  controls, routing, and model flexibility.

Samebase must therefore name what remains valuable above the user's coding agent: the base,
provisioning, owned accounts, connected-app inventory, verification, and repair.

## Best Uses, Ranked

### 1. Short explainer video

Best fit. Motion can reveal the analogy before the narration states the literal product. Use it as a
landing embed, launch clip, or social cut.

### 2. One sales-deck slide

Show two columns:

- bundled builder: another AI interface plus app operations;
- Samebase: the user's existing agent plus a proven, agent-operable base.

The speaker can resolve objections immediately, which makes the metaphor safer than standalone copy.

### 3. A compact "why no built-in AI?" landing beat

The metaphor can support the existing "We resell nothing" section. It should not replace the hero or
the one-base inventory section.

### 4. Founder explanation or podcast answer

It is a useful conversational bridge when someone asks why Samebase does not contain an AI chat. The
founder can immediately add the ownership, inventory, and repair details.

### Do not use it as

- the product category;
- the main homepage headline;
- a pricing guarantee;
- an explanation aimed at people who do not already use a coding agent;
- the only explanation of Samebase's value.

## Video Directions

### Direction A: The Missing Ingredient

**Length:** 30 to 40 seconds

**Role:** recommended first Remotion experiment

An agent writes code. The code reaches the edge of its window and stops at empty spaces labeled
repository, backend, deployment, previews, inventory, and repair. A small Samebase measure connects
the pieces. The visual then becomes the real Samebase dashboard and a real agent action.

Voiceover:

> Your coding agent can write the app. The missing ingredient is everything that makes it real and
> keeps it manageable. Samebase gives the agent you already use one proven base it can create,
> inventory, and repair, on accounts you own.

End card:

> Your agent writes it. Samebase makes it real.

This preserves the concentrate idea without claiming that AI is homogeneous or that Samebase is a
packet of prompts.

### Direction B: Stop Shipping Water

**Length:** 15 to 25 seconds

**Role:** high-attention hook variant

A heavy bottle labeled "another bundled AI" moves through trucks and warehouses. Cut to Codex or
Claude already open on the user's computer. The bottle disappears. Samebase connects the agent to
GitHub, Convex, and Cloudflare, then shows the app in inventory.

Voiceover:

> Why buy another AI inside an app builder when you already chose your coding agent? Keep your AI.
> Give it Samebase: one proven base, on accounts you own.

End card:

> Keep your agent. Add Samebase.

This is the purest use of the original metaphor and the easiest to remember. It also carries the
highest risk of reducing competitors to token resale, so it should be tested against Direction A.

### Direction C: One App Versus Ten

**Length:** 45 to 60 seconds

**Role:** strongest strategic story

One improvised app setup looks manageable. It multiplies into ten different stacks, account maps,
deployment instructions, and repair notes. They collapse into one reusable base feeding different
app shapes, followed by the real Samebase inventory.

Voiceover:

> For one app, almost any setup feels simple. By the fifth or tenth, every different stack becomes
> another system to remember. Samebase lets the coding agent you already use repeat one proven base
> across every connected app. The products stay different. The setup, inventory, and repair model
> stay the same.

End card:

> More products. Fewer systems to maintain.

This is less literally about water, but it expresses Samebase's compounding value most accurately.

## Copy Worth Testing

Strong literal bridge:

> Bring the coding agent you already chose. Samebase gives it one proven base to create and manage
> across your apps.

Short campaign line:

> Keep your agent. Add Samebase.

More visual:

> Your AI is already on your desk. Samebase is the base it builds on.

Sharper anti-bundling version:

> Do not buy another AI wrapper. Give your agent the missing operating layer.

The last option is useful for an ad test, but too adversarial for the durable brand voice.

Avoid:

- "AI is just water."
- "Samebase is concentrated knowledge."
- "Get the same app builder for less."
- "Just add AI."

"Just add AI" is memorable but reverses the product relationship. It makes Samebase sound like a
builder waiting for a model key, while the product is a tool the user's existing agent invokes.

## Validation Before Full Production

Start with a storyboard or low-cost animatic after the Remotion package lands. Test Direction A
against Direction B before investing in polished assets.

After one unaided viewing, ask:

1. Does Samebase include an AI subscription?
2. What does Samebase actually do?
3. Where do the code, backend, and hosting live?
4. What would you still have if Samebase disappeared?
5. What was the video's main claim about cost?

The concept passes when most viewers answer:

- it works with the coding agent they already use;
- it supplies a repeatable app base plus setup and ongoing management;
- the repository and infrastructure stay in their accounts;
- the claim is avoiding bundled resale, not guaranteed universal savings.

Also run the storyboard transcript through the established fresh-agent evaluation method. An agent
should reconstruct the same product boundary without access to repository context.

## Decision

The idea is worth keeping and testing. Its value is creative, not categorical.

The concentrate metaphor can give Samebase a memorable answer to "why is there no AI chat in the
product?" and a visually strong video opening. It becomes misleading when asked to explain the whole
company, because Samebase is not a cheaper packet that recreates the same app builder.

The durable positioning remains:

> Samebase lets the coding agent you already use create and manage the same proven base across every
> app.

The concentrate metaphor is the hook that helps someone remember why the agent is theirs and the
base is Samebase's job.
