## Why this matters

Two internal Convex mutations have zero callers anywhere in the codebase (verified by grep at the
planned-at commit, excluding `_generated`):

1. `applyUpdatesToStaging` in `collaborative.ts` — dead, and it also contains a latent bug:
   `Math.max(...[])` returns `-Infinity`, so an empty `updates` array would corrupt
   `staging.version`. Deleting it removes both the dead code and the trap.
2. `cleanupCloudflareData` in `cleanupCloudflare.ts` — a spent one-shot migration: it reads fields
   that no longer exist in the schema (via a `readUnknownField` helper that bypasses typing) and
   full-table-scans four tables. It has already served its purpose; git history preserves it.

The repo's own guardrails (AGENTS.md "Code Guardrails") are explicit: "Do not keep dead migration
scaffolding" and "delete-first is the default."
