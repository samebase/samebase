## Why this matters

`AGENTS.md` and `README.md` are loaded by every coding agent and read by every new contributor; in
this repo they are effectively configuration. Two statements are objectively wrong today:

1. `AGENTS.md` says the frontend is "React 18, Vite, React Router 7" — the app actually ships React
   19 with TanStack Start + TanStack Router. Agents that trust this line reach for the wrong router
   APIs.
2. `README.md` says the starter seed source of truth is `apps/noter-starter-template` and shows it
   in the project-structure diagram — that directory was deleted (commit `aa1dede1c`, 2026-04-29);
   the source of truth is now the external `notermd/app` GitHub repository, exported by a script.
   New developers search for a directory that does not exist.
