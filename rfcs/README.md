# RFCs

This folder is for proposals, pilots, rollout plans, and requests for comments
that are still under discussion or are not yet committed source-of-truth
implementation docs.

Use `rfcs/` when the repo needs a proposed direction, an implementation plan
that still needs acceptance, or a phased rollout document for work that is not
yet the accepted current contract.

Use `research/` instead when the document is still primarily evidence gathering,
benchmarking, or exploratory analysis rather than a concrete proposal.

Move a doc from `rfcs/` to `specs/` only after the decision is accepted and the
implementation is active. Move it to `archive/` if it becomes historical without
becoming the active source of truth.
