# Archive

This folder is for superseded, canceled, or historical docs that are worth
keeping for context but should not guide new implementation.

When a spec or RFC no longer describes current reality and should not remain an
active planning document, move it here instead of leaving it in `specs/` or
`rfcs/`.

Archive is for history, not for active guidance. If a document still matters to
current decisions, keep it in `specs/`, `rfcs/`, `research/`, or `docs/`
instead.
