# Pricing

Start free. Upgrade when you need more connections.

| GitHub owner        | Plan | Monthly base | Connections | Included members |
| ------------------- | ---- | -----------: | ----------: | ---------------: |
| Personal account    | Free |           $0 |          12 |                1 |
| GitHub organization | Free |           $0 |           6 |                2 |
| Any owner           | Pro  |           $4 |         120 |                2 |

Each repository connected to Samebase is one connection. Members above the included limit need Pro
and a seat at $2 per month. A pending invitation does not use a seat.

GitHub and Convex bill their own usage directly. Samebase resells none of it.

If Pro ends, nothing is disconnected or deleted. An organization above its Free limit cannot connect
another repository until it is under the limit again.
