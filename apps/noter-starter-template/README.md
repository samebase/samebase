# Noter Starter Template

This project is the seeded baseline for newly created noter-managed
repositories.

## Stack

- React + Vite
- Convex backend
- Tailwind CSS
- shadcn/ui primitives

## Scripts

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm run check
```

## Template Manifest

```bash
pnpm run template:export
```
