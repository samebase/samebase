# Security

Report vulnerabilities privately to [contact@samebase.com](mailto:contact@samebase.com). Do not put
credentials, private repository contents, or exploit details in a public issue.

Include the affected component or URL, the commit or package version, the expected result, the
actual result, and the minimum steps needed to reproduce the problem. Use test data where possible
and redact secrets.

This policy covers the Samebase service and the code maintained in this repository. For a
third-party dependency, use that project's security policy. Use
[GitHub Issues](https://github.com/samebase/samebase/issues) for non-sensitive bugs and support.
